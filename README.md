# Star Words（星词岛）

给大约 5 岁孩子的 Vue 3 移动端 H5。主路径是 **动物岛**，内容按 RISE Mart P1 课表从 L49 起：12 章 × 每章 4 课。现在能玩的是第 1 章四课（字母 O / V / L / K），每课大约 5 关。后面的课显示「即将开放」。关卡数读配置，不要写死。试玩没有 `?level=` 时仍从旧 15 词库抽一小撮。已过关用「再玩一次」，不加首次通关奖励。**字母工坊**、**单词图鉴**只是弱入口。**贴纸相册**用来看已经拿到的贴纸。纯前端，无后端。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里的本地地址（默认 `http://localhost:5173/idea_nb_en/`）。手机预览可用同一 Wi-Fi 下的局域网地址。

```bash
npm run build
```

产物在 `dist/`，可直接当静态页部署。`npm run preview` 可本地预览打包结果。

## 玩法一览（试玩全部玩法）

1. 打开首页，点「玩法一览」（在「去动物岛」下面）。首页还可进「贴纸相册」和弱入口「单词图鉴」。
2. 列表里有主线玩法 + 唱一唱 / 找一找，点「试玩」进入该关。
3. 试玩带 `?demo=1`，完成后回一览，**不会**加首次通关星星或推进章节。
4. 主线从「去动物岛」按顺序走 闪卡翻翻 → 地鼠词 → 拖一拖 → 读词钓鱼 → 回声跟读 → 小书点读 → 听音拼一拼 → 章节回顾。每关路由带 `?level=ch1-x`，通关调用 `completeLevel` 后立刻进下一关；终章后再进章节奖励页。找一找 / 唱一唱只在一览试玩。

## MVP 覆盖

- **首页**：主按钮「去动物岛」；标题下是目标条（「第N章·第M课 x/y」+ 下一关 + 可选焦点词 + 过关星星条 + CTA）。还没做好的课写「即将开放」
- **设置**：齿轮里有「设置当前课」（把更早的课标成已过，并补星星和章节徽章）、「初始化」（清空进度）、「完全化」（按配置打满）。三者都读 `chapters` / 音族 / 贴纸配置，不写死课数
- **单词图鉴**：格子展示全部音族词（旧 `-at` 15 词 + `-ap` / `-og` / `-ck` / `-an`）；已解锁显示词卡或 emoji + 英文，未解锁剪影问号；点已解锁词会 TTS 朗读。主线点对 / 地鼠点对 / 拖对 / 听音拼一拼拼对 / 钓到 / 跟读通过，以及一览找一找点中、唱一唱「我唱好了」即写入 `starWords.v2` 解锁；点错或只听不解锁，逛图鉴不加当日星星
- **贴纸相册**：格子展示日奖占位 + 三章徽章（耳朵 / 爪印 / 叶子 / 贝壳 / 太阳 / -ap 派对 / 爪印徽章 / 小星星）；已拥有亮色，未拥有剪影问号；一张都没有时提示先去玩派对。只展示，不交换、不花费。入口在首页、动物岛大厅、完成页
- **动物岛大厅**：先列 12 章，点开再列 4 课（小字课表范围），再进该课关卡。第 1 章可玩；后面的章要等前一章四课都过。没有内容的课显示「即将开放」
- **玩法一览**：列出主线玩法 + 唱一唱 / 找一找，点进 demo 试玩，不加当日星星。主路径不链到按章练一练画廊；已过关重玩走「再玩一次」
- **听音拼一拼 / Sound Spell**：正式关（`/sound-spell`，chN-7）。听目标词（喇叭随时再听），用字母块按顺序点或拖进 C-V-C 格子；正确字母 + 1–2 个相近 CVC 干扰。词表读该关 `focusWord` / `appearWords` / `words`；试玩无 id 从 15 词库抽一小撮。点错轻晃再听，没有红叉。拼对解锁图鉴；通关 `completeLevel` 立刻进章节回顾；`?demo=1` 不加星
- **读词钓鱼 / Word Fish**：有 `?level=` 时用该关词表（现为 chN-4）；试玩无 id 仍从 15 词抽 3 条单词鱼（鱼身贴词卡图）；读出单词即挂钩吊进网里，点鱼或点喇叭也能玩；试玩不加星
- **Echo Cave**：有关卡 id 时用该关词表（ch2-5 走完 frog→hog）；试玩无 id 仍抽 3 词；每轮听单词 + 一句短句再跟读；有 `SpeechRecognition` 就听，没有或失败可点「我说好了」
- **小书点读 / Story Book**：正式关（`/story-book`，chN-6）。封面是章节主题 emoji + 书名（点书名听封面）；随后 3–5 页，每页一句短句（关卡词表 + `shortSentences`）+ 焦点词图。第一次听句子前先轻轻高亮焦点 CVC，鼓励试拼读，不是测验。点句子 / 喇叭听整句，点词听单词。最后一页庆祝后 `completeLevel` 进听音拼一拼；`?level=` 与其它关相同，试玩无 id 从 15 词库抽一小撮
- **Flash Flip 闪卡翻翻**：有关卡 id 时用该关 focus / 出场词；试玩无 id 仍抽 4 词。学习阶段一张一词、按实际词数显示进度（如 1/3），「下一张」/「上一张」手动翻完后才「开始找一找」点对图卡；试玩不加星，点对解锁图鉴
- **Whack Word 地鼠词**：有关卡 id 时用该关词表；试玩无 id 仍抽 5 词；地鼠弹出词卡图+词，听目标词点对的那只；点对 4 次过关，点错轻晃不倒计时卡死；试玩不加星，点对解锁图鉴
- **Drag Sort 拖一拖**：有关卡 id 时用该关词表；试玩无 id 仍抽 3 词，把纯英文单词芯片拖到对应词卡篮子（篮子无中文，芯片无图；英语 TTS 演示）
- **Sing Along 唱一唱**：每局抽 3 词，两句 chant 高亮，点「我唱好了」（不测音高）；点成功解锁图鉴，不加当日星
- **Find Scene 找一找**：派对场景用 Pixi 画布点出本局 3 个词卡（Vue 壳保留；试玩不加星）；点中目标解锁图鉴
- **词卡资源**：`public/word-cards/{word}.webp`（Style-5 描边软陶，512px WebP），路径走 Vite `base` `/idea_nb_en/`；图鉴与各关出图优先用词卡，加载失败回退 emoji
- **Day Complete**：庆祝刚通关的那一章（`/day-complete?chapter=chN`），展示过关星星条和该章亮格（完成页不加星）；首次展示该章徽章（派对徽章 / 爪印徽章 / 小星星徽章）；岛日 +1 只作后台展示 / 分析（同日一次，封顶 7），完成页不再画 7 日格子，也不锁下一关；可回家或去看贴纸相册；想再玩回该章点已过关「再玩一次」
- **字母工坊**：列出全部音族词，可复习重玩两关；不发首次通关奖励
- **本地存储**：统一键 `starWords.v2`（终身星星 / 贴纸 / 图鉴解锁 / 章节关卡 / 动物岛 0–7 日 / 当日文案）。旧键 `starWords.v1` 与 `starWords.atlas.v1` 会在首次读取时迁入；旧日链存档按玩法映射到第一章。v3 的 6 关章节存档升到 persist `version: 4`：按玩法重映射（旧 chN-4 钓鱼→现 chN-4）。v4 的 8 关存档升到 `version: 5`：再按玩法重映射（旧 chN-4 听音拼一拼→现 chN-7，旧钓鱼/回声/小书各前移一档），终章若已过但新关未过会重新锁定，已开后章不软锁。章节进度跨日保留。关卡首次通关 +1 星；重玩、`?practice=1`、`?demo=1`、`?review=1`、找一找 / 唱一唱不加星，也不重复发章节徽章。设置里「初始化」会清掉这些进度键（含章节），不删词卡图；「完全化」按配置打满进度，不写死章节 id
- **数据驱动**：`src/data/phonicsFamily.ts` 含旧 `-at` 15 词与 `-ap` / `-og` / `-ck` / `-an`；动物岛三章关卡表在 `src/data/chapters.ts`（ch1「-ap 派对」、ch2「听声找伙伴」、ch3「石头袜子」）。主线玩法经 `src/data/gateWords.ts` 读该关词表（ch1：cap/map/nap…；ch2：frog/log/fog/jog/hog；ch3：duck/rock/sock/lock/pack）。短句在 `shortSentences.ts`。章内顺序解锁；`isChapterUnlocked`：ch2 需 ch1 全通（或该章已有进度），ch3 同理。无参 `getNextLevel()` 会跨章。大厅列出三章入口后再进该章关卡列表。设置「初始化」清空全部章节进度；「完全化」仍从配置收集词 / 关 / 贴纸

游戏内角色口语以英语为主；家长说明用中文。点对 / 通关表扬从英语词库随机抽，不总是 Yes / Great job。没有红叉、没有失败卡死、没有比分。

## 技术

Vue 3 + Vite + TypeScript + Vue Router。状态用 composable + `localStorage`。语音用 Web Speech API（`speechSynthesis` / `SpeechRecognition`）。动效用 GSAP，短提示音用 Howler，拖一拖用 `@vueuse/gesture` 磁吸落篮。找一找与读词钓鱼用 PixiJS 画布，其它关仍是 Vue。
