# Star Words（星词岛）

给大约 5 岁孩子的 Vue 3 移动端 H5。主路径是 **动物岛**（Animals theme island）：先进入小岛大厅，再按章节关卡顺序玩（闪卡翻翻 → 地鼠词 → 拖一拖 → 读词钓鱼 → 回声跟读 → 章节回顾），通关立刻开下一关，不等日历日。当前词库 15 个英语词，每局只抽一小撮。**字母工坊**、**单词图鉴**只是弱入口。**贴纸相册**用来看已经拿到的贴纸。纯前端，无后端。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里的本地地址（默认 `http://localhost:5173/idea_nb_en/`）。手机预览可用同一 Wi-Fi 下的局域网地址。

```bash
npm run build
```

产物在 `dist/`，可直接当静态页部署。`npm run preview` 可本地预览打包结果。

## 玩法一览（试玩全部玩法）

1. 打开首页，点「玩法一览」（在「去动物岛」下面）。首页还可进「贴纸相册」和弱入口「单词图鉴」。
2. 列表里有 7 种玩法，点「试玩」进入该关。
3. 试玩带 `?demo=1`，完成后回一览，**不会**加首次通关星星或推进章节。
4. 主线从「去动物岛」按顺序走 闪卡翻翻 → 地鼠词 → 拖一拖 → 读词钓鱼 → 回声跟读 → 章节回顾。找一找 / 唱一唱只在一览试玩。

## MVP 覆盖

- **首页**：主按钮「去动物岛」；标题下是目标条（一条主任务 + 可选焦点词 + 星星条 空/实 6 星）；次入口「玩法一览」「贴纸相册」；弱入口「字母工坊 / 复习音族」「单词图鉴」；右上角齿轮打开设置
- **设置**：首页 / 动物岛大厅齿轮进入；「初始化」会二次确认后清空本地进度（星星 / 贴纸 / 图鉴 / 章节关卡 / 岛日 / 今日任务），词卡图片保留；贴纸相册也会变空
- **单词图鉴**：格子展示动物岛 15 词 + `-ap` / `-an` 槽位；已解锁显示描边软陶词卡 + 英文，未解锁剪影问号；点已解锁词会 TTS 朗读。主线点对 / 地鼠点对 / 拖对 / 钓到 / 跟读通过，以及一览找一找点中、唱一唱「我唱好了」即写入 `starWords.v2` 解锁；点错或只听不解锁，逛图鉴不加当日星星
- **贴纸相册**：格子展示 6 张目录贴纸（耳朵 / 爪印 / 叶子 / 贝壳 / 太阳 / -at 派对徽章）；已拥有亮色，未拥有剪影问号；一张都没有时提示先去玩派对。只展示，不交换、不花费。入口在首页、动物岛大厅、完成页
- **动物岛大厅**：进度是「第1章 x/6 关」；6 关亮格跟已通关数走。关卡列表 ch1-1…ch1-6 显示未开 / 可玩 / 已过；可玩点进该关，未开轻提示「先过上一关吧」。主按钮高亮 `getNextLevel()`（通关立刻下一关）。不再按日历锁关，也不再展示旧的 7 日格子 / 今日主线四关
- **玩法一览**：列出 7 种玩法，点进 demo 试玩，不加当日星星
- **读词钓鱼 / Word Fish**：每局从 15 词抽出 3 条单词鱼（鱼身贴词卡图）；读出单词即挂钩吊进网里，点鱼或点喇叭也能玩；试玩不加星
- **Echo Cave**：每局抽 3 词；TTS 范读后跟读；有 `SpeechRecognition` 就听，没有或失败可点「我说好了」
- **Flash Flip 闪卡翻翻**：每局抽 4 词，先翻卡看词卡图+词并听读（约 30–40 秒热身），再听词点对图卡；试玩不加星，点对解锁图鉴
- **Whack Word 地鼠词**：每局抽 5 词；地鼠弹出词卡图+词，听目标词点对的那只；点对 4 次过关，点错轻晃不倒计时卡死；试玩不加星，点对解锁图鉴
- **Drag Sort 拖一拖**：每局抽 3 词，把纯英文单词芯片拖到对应词卡篮子（篮子无中文，芯片无图；英语 TTS 演示）
- **Sing Along 唱一唱**：每局抽 3 词，两句 chant 高亮，点「我唱好了」（不测音高）；点成功解锁图鉴，不加当日星
- **Find Scene 找一找**：派对场景用 Pixi 画布点出本局 3 个词卡（Vue 壳保留；试玩不加星）；点中目标解锁图鉴
- **词卡资源**：`public/word-cards/{word}.webp`（Style-5 描边软陶，512px WebP），路径走 Vite `base` `/idea_nb_en/`；图鉴与各关出图优先用词卡，加载失败回退 emoji
- **Day Complete**：庆祝第一章结束，展示星星条（完成页不加星）；首次展示 ch1-6 的章节徽章；岛日 +1 只作展示（同日一次，封顶 7），不锁下一关；可回家或去看贴纸相册
- **字母工坊**：列出当前 15 个派对词，可复习重玩两关；不发首次通关奖励
- **本地存储**：统一键 `starWords.v2`（终身星星 / 贴纸 / 图鉴解锁 / 章节关卡 / 动物岛 0–7 日 / 当日文案）。旧键 `starWords.v1` 与 `starWords.atlas.v1` 会在首次读取时迁入；旧日链存档映射到第一章（已打卡则 ch1-1…ch1-5 已通、ch1-6 解锁，保留图鉴和贴纸）。章节进度跨日保留。关卡首次通关 +1 星；重玩、`?demo=1`、`?review=1`、找一找 / 唱一唱不加星。设置里「初始化」会清掉这些进度键（含章节），不删词卡图
- **数据驱动**：`src/data/phonicsFamily.ts` 当前 `-at` 词库 15 个，并已预留 `-ap` / `-an`；第一章关卡表在 `src/data/chapters.ts`

游戏内角色口语以英语为主；家长说明用中文。点对 / 通关表扬从英语词库随机抽，不总是 Yes / Great job。没有红叉、没有失败卡死、没有比分。

## 技术

Vue 3 + Vite + TypeScript + Vue Router。状态用 composable + `localStorage`。语音用 Web Speech API（`speechSynthesis` / `SpeechRecognition`）。动效用 GSAP，短提示音用 Howler，拖一拖用 `@vueuse/gesture` 磁吸落篮。找一找与读词钓鱼用 PixiJS 画布，其它关仍是 Vue。
