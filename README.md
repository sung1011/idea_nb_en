# Star Words（星词岛）

给大约 5 岁孩子的 Vue 3 移动端 H5。主路径是 **动物岛**（Animals theme island）：先进入小岛大厅，再按章节关卡顺序玩（闪卡翻翻 → 地鼠词 → 拖一拖 → 听音拼一拼 → 读词钓鱼 → 回声跟读 → 小书点读 → 章节回顾），通关立刻开下一关，不等日历日。关卡总数读 `chapters` 配置的 `levels.length`（当前 8，不要写死 6）。当前词库 15 个英语词；主线按该关 `chapters.ts` 词表出词，试玩没有 `?level=` 时每局只从 15 词抽一小撮。已过关用「再玩一次」重玩，不加首次通关奖励。**字母工坊**、**单词图鉴**只是弱入口。**贴纸相册**用来看已经拿到的贴纸。纯前端，无后端。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里的本地地址（默认 `http://localhost:5173/idea_nb_en/`）。手机预览可用同一 Wi-Fi 下的局域网地址。

```bash
npm run build
```

产物在 `dist/`，可直接当静态页部署。`npm run preview` 可本地预览打包结果。

## 玩法一览（试玩全部玩法）

1. 打开首页，点「玩法一览」（在「去动物岛」下面）。首页还可进「贴纸相册」和弱入口「单词图鉴」。
2. 列表里有主线玩法 + 唱一唱 / 找一找，点「试玩」进入该关。
3. 试玩带 `?demo=1`，完成后回一览，**不会**加首次通关星星或推进章节。
4. 主线从「去动物岛」按顺序走 闪卡翻翻 → 地鼠词 → 拖一拖 → 听音拼一拼 → 读词钓鱼 → 回声跟读 → 小书点读 → 章节回顾。每关路由带 `?level=ch1-x`，通关调用 `completeLevel` 后立刻进下一关；终章后再进章节奖励页。找一找 / 唱一唱只在一览试玩。

## MVP 覆盖

- **首页**：主按钮「去动物岛」；标题下是章节目标条（当前下一关所在章「第N章 x/N 关」+「下一关：玩法名」+ 可选焦点词 + 过关星星条 + CTA 直达无参 `getNextLevel()`，例如 ch1 通关后指向 ch2-1）；不挂练一练；岛卡内嵌当前章亮格（格数 = `levelTotal`）；次入口「玩法一览」「贴纸相册」；弱入口「字母工坊 / 复习音族」「单词图鉴」；右上角齿轮打开设置
- **设置**：首页 / 动物岛大厅齿轮进入；「初始化」会二次确认后清空本地进度（星星 / 贴纸 / 图鉴 / 章节关卡），词卡图片保留；贴纸相册也会变空。「完全化」是调试按钮，确认后按 `chapters` / 音族词库 / 贴纸目录一键打满全部进度，不加死章节 id
- **单词图鉴**：格子展示动物岛 15 词 + `-ap` / `-an` 槽位；已解锁显示描边软陶词卡 + 英文，未解锁剪影问号；点已解锁词会 TTS 朗读。主线点对 / 地鼠点对 / 拖对 / 钓到 / 跟读通过，以及一览找一找点中、唱一唱「我唱好了」即写入 `starWords.v2` 解锁；点错或只听不解锁，逛图鉴不加当日星星
- **贴纸相册**：格子展示日奖占位 + 三章徽章（耳朵 / 爪印 / 叶子 / 贝壳 / 太阳 / -at 派对 / 爪印徽章 / 小星星）；已拥有亮色，未拥有剪影问号；一张都没有时提示先去玩派对。只展示，不交换、不花费。入口在首页、动物岛大厅、完成页
- **动物岛大厅**：先列三章（「-at 派对」「听声找伙伴」「点心与天空」）。第1章永远可进；后两章未开时软锁，提示「先通关上一章吧」。点开已解锁章后，关卡列表显示未开 / 可玩 / 已过；已过关写「再玩一次」。未开关轻提示「先过上一关吧」。主按钮高亮该章或跨章 `getNextLevel()`。想再玩就点已过的关或重玩结束层「再玩一次」，不另挂练一练。不再按日历锁关
- **玩法一览**：列出主线玩法 + 唱一唱 / 找一找，点进 demo 试玩，不加当日星星。主路径不链到按章练一练画廊；已过关重玩走「再玩一次」
- **听音拼一拼 / Sound Spell**：本阶段 stub（`/sound-spell`，chN-4）。听一个 CVC 词，点字母块拼出来（不是打字考试）；通关调用 `completeLevel`
- **读词钓鱼 / Word Fish**：有 `?level=` 时用该关词表（现为 chN-5）；试玩无 id 仍从 15 词抽 3 条单词鱼（鱼身贴词卡图）；读出单词即挂钩吊进网里，点鱼或点喇叭也能玩；试玩不加星
- **Echo Cave**：有关卡 id 时用该关词表（ch2-6 走完五只动物）；试玩无 id 仍抽 3 词；TTS 范读后跟读；有 `SpeechRecognition` 就听，没有或失败可点「我说好了」
- **小书点读 / Story Book**：本阶段 stub（`/story-book`，chN-7）。封面 + 几页点读，鼓励对焦点词试着拼读；通关调用 `completeLevel`
- **Flash Flip 闪卡翻翻**：有关卡 id 时用该关 focus / 出场词；试玩无 id 仍抽 4 词，先翻卡看词卡图+词并听读（约 30–40 秒热身），再听词点对图卡；试玩不加星，点对解锁图鉴
- **Whack Word 地鼠词**：有关卡 id 时用该关词表；试玩无 id 仍抽 5 词；地鼠弹出词卡图+词，听目标词点对的那只；点对 4 次过关，点错轻晃不倒计时卡死；试玩不加星，点对解锁图鉴
- **Drag Sort 拖一拖**：有关卡 id 时用该关词表；试玩无 id 仍抽 3 词，把纯英文单词芯片拖到对应词卡篮子（篮子无中文，芯片无图；英语 TTS 演示）
- **Sing Along 唱一唱**：每局抽 3 词，两句 chant 高亮，点「我唱好了」（不测音高）；点成功解锁图鉴，不加当日星
- **Find Scene 找一找**：派对场景用 Pixi 画布点出本局 3 个词卡（Vue 壳保留；试玩不加星）；点中目标解锁图鉴
- **词卡资源**：`public/word-cards/{word}.webp`（Style-5 描边软陶，512px WebP），路径走 Vite `base` `/idea_nb_en/`；图鉴与各关出图优先用词卡，加载失败回退 emoji
- **Day Complete**：庆祝刚通关的那一章（`/day-complete?chapter=chN`），展示过关星星条和该章亮格（完成页不加星）；首次展示该章徽章（派对徽章 / 爪印徽章 / 小星星徽章）；岛日 +1 只作后台展示 / 分析（同日一次，封顶 7），完成页不再画 7 日格子，也不锁下一关；可回家或去看贴纸相册；想再玩回该章点已过关「再玩一次」
- **字母工坊**：列出当前 15 个派对词，可复习重玩两关；不发首次通关奖励
- **本地存储**：统一键 `starWords.v2`（终身星星 / 贴纸 / 图鉴解锁 / 章节关卡 / 动物岛 0–7 日 / 当日文案）。旧键 `starWords.v1` 与 `starWords.atlas.v1` 会在首次读取时迁入；旧日链存档按玩法映射到第一章。v3 的 6 关章节存档升到 persist `version: 4`：按玩法重映射（旧 chN-4 钓鱼→新 chN-5），终章若已过但新关未过会重新锁定，已开后章不软锁。章节进度跨日保留。关卡首次通关 +1 星；重玩、`?practice=1`、`?demo=1`、`?review=1`、找一找 / 唱一唱不加星，也不重复发章节徽章。设置里「初始化」会清掉这些进度键（含章节），不删词卡图；「完全化」按配置打满进度，不写死章节 id
- **数据驱动**：`src/data/phonicsFamily.ts` 当前 `-at` 词库 15 个，并已预留 `-ap` / `-an`；动物岛三章关卡表在 `src/data/chapters.ts`（ch1「-at 派对」、ch2「听声找伙伴」、ch3「点心与天空」）。主线玩法经 `src/data/gateWords.ts` 读该关词表（ch2：dog/pig/duck/bird/fish；ch3：cup/cake/ball/sun/star，终章可加 -at 复习）。章内顺序解锁；`isChapterUnlocked`：ch2 需 ch1 全通（或该章已有进度），ch3 同理。无参 `getNextLevel()` 会跨章。大厅列出三章入口后再进该章关卡列表。设置「初始化」清空全部章节进度

游戏内角色口语以英语为主；家长说明用中文。点对 / 通关表扬从英语词库随机抽，不总是 Yes / Great job。没有红叉、没有失败卡死、没有比分。

## 技术

Vue 3 + Vite + TypeScript + Vue Router。状态用 composable + `localStorage`。语音用 Web Speech API（`speechSynthesis` / `SpeechRecognition`）。动效用 GSAP，短提示音用 Howler，拖一拖用 `@vueuse/gesture` 磁吸落篮。找一找与读词钓鱼用 PixiJS 画布，其它关仍是 Vue。
