# Star Words（星词岛）

给大约 5 岁孩子的 Vue 3 移动端 H5。每日主路径是 **动物岛**（Animals theme island）：先进入小岛大厅，再走完今日主线（闪卡翻翻或地鼠词 → 拖一拖 → 读词钓鱼 → 回声跟读），收集星星。当前词库 15 个英语词，每局只抽一小撮。**字母工坊**、**单词图鉴**只是弱入口，不是每日作业。纯前端，无后端。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里的本地地址（默认 `http://localhost:5173/idea_nb_en/`）。手机预览可用同一 Wi-Fi 下的局域网地址。

```bash
npm run build
```

产物在 `dist/`，可直接当静态页部署。`npm run preview` 可本地预览打包结果。

## 玩法一览（试玩全部玩法）

1. 打开首页，点「玩法一览」（在「去动物岛」下面）。首页弱入口还可进「单词图鉴」。
2. 列表里有 7 种玩法，点「试玩」进入该关。
3. 试玩带 `?demo=1`，完成后回一览，**不会**加当日星星或打卡。
4. 每日作业从「去动物岛」→「今日主线」走 闪卡翻翻或地鼠词 → 拖一拖 → 读词钓鱼 → 回声跟读。找一找 / 唱一唱只在一览试玩。

## MVP 覆盖

- **首页**：主按钮「去动物岛」；标题下是今日目标条（一条主任务 + 可选焦点词 + 今日星星条 空/实 4 星）；次入口「玩法一览」；弱入口「字母工坊 / 复习音族」「单词图鉴」；右上角齿轮打开设置
- **设置**：首页 / 动物岛大厅齿轮进入；「初始化」会二次确认后清空本地进度（星星 / 贴纸 / 图鉴 / 岛日 / 今日任务），词卡图片保留
- **单词图鉴**：格子展示动物岛 15 词 + `-ap` / `-an` 槽位；已解锁显示描边软陶词卡 + 英文，未解锁剪影问号；点已解锁词会 TTS 朗读。主线点对 / 地鼠点对 / 拖对 / 钓到 / 跟读通过，以及一览找一找点中、唱一唱「我唱好了」即写入 `starWords.v2` 解锁；点错或只听不解锁，逛图鉴不加当日星星
- **动物岛大厅**：岛名下是今日目标条（默认「今天走完派对四关」，完成打勾；有焦点词时「多听一听 cat」；下方今日星星条）；小岛场景下是 7 日亮格（读 `animalsIslandDays`，文案「小岛亮了 n/7 天」；亮格庆祝、空格柔和；7/7 只软提示，不解锁第二座岛）；进度 0/4，每关旁一颗空/实星；「今日主线」按 `chainStep` 进入当天第一关（偶数日闪卡翻翻，奇数日地鼠词）；右上角同样有设置齿轮
- **玩法一览**：列出 7 种玩法，点进 demo 试玩，不加当日星星
- **读词钓鱼 / Word Fish**：每局从 15 词抽出 3 条单词鱼（鱼身贴词卡图）；读出单词即挂钩吊进网里，点鱼或点喇叭也能玩；试玩不加星
- **Echo Cave**：每局抽 3 词；TTS 范读后跟读；有 `SpeechRecognition` 就听，没有或失败可点「我说好了」
- **Flash Flip 闪卡翻翻**：每局抽 4 词，先翻卡看词卡图+词并听读（约 30–40 秒热身），再听词点对图卡；试玩不加星，点对解锁图鉴
- **Whack Word 地鼠词**：每局抽 5 词；地鼠弹出词卡图+词，听目标词点对的那只；点对 4 次过关，点错轻晃不倒计时卡死；试玩不加星，点对解锁图鉴
- **Drag Sort 拖一拖**：每局抽 3 词，把纯英文单词芯片拖到对应词卡篮子（篮子无中文，芯片无图；英语 TTS 演示）
- **Sing Along 唱一唱**：每局抽 3 词，两句 chant 高亮，点「我唱好了」（不测音高）；点成功解锁图鉴，不加当日星
- **Find Scene 找一找**：派对场景用 Pixi 画布点出本局 3 个词卡（Vue 壳保留；试玩不加星）；点中目标解锁图鉴
- **词卡资源**：`public/word-cards/{word}.webp`（Style-5 描边软陶，512px WebP），路径走 Vite `base` `/idea_nb_en/`；图鉴与各关出图优先用词卡，加载失败回退 emoji
- **Day Complete**：庆祝派对成功，展示今日星星条（完成页不加星）；当日首次通关发 1 张贴纸（目录下一张未拥有的）并推进动物岛天数（同日一次，封顶 7）；再进只展示已领状态，回首页
- **字母工坊**：列出当前 15 个派对词，可复习重玩两关；不发首次通关奖励
- **本地存储**：统一键 `starWords.v2`（当日星星 / 终身星星 / 贴纸 / 图鉴解锁 / 动物岛 0–7 日 / 当日任务）。旧键 `starWords.v1` 与 `starWords.atlas.v1` 会在首次读取时迁入。日期按 Asia/Shanghai 日历日重置当日进度。主线关首次通关 +1 当日星；重玩、`?demo=1`、`?review=1`、找一找 / 唱一唱不加当日星。设置里「初始化」会清掉这些进度键，不删词卡图
- **数据驱动**：`src/data/phonicsFamily.ts` 当前 `-at` 词库 15 个，并已预留 `-ap` / `-an`

游戏内角色口语以英语为主；家长说明用中文。点对 / 通关表扬从英语词库随机抽，不总是 Yes / Great job。没有红叉、没有失败卡死、没有比分。

## 技术

Vue 3 + Vite + TypeScript + Vue Router。状态用 composable + `localStorage`。语音用 Web Speech API（`speechSynthesis` / `SpeechRecognition`）。动效用 GSAP，短提示音用 Howler，拖一拖用 `@vueuse/gesture` 磁吸落篮。找一找与读词钓鱼用 PixiJS 画布，其它关仍是 Vue。
